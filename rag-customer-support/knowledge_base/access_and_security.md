# Account access and security

## Multi-factor authentication
All employees must enable multi-factor authentication (MFA) for administrator accounts and remote access. Security operations can reset MFA after verifying the employee through the approved identity-verification process. Never request a user's password or one-time authentication code in a support ticket.

## Password policy
Passwords must be at least 14 characters. Passwords must not be reused across company and personal accounts. If an employee suspects a credential has been exposed, they must reset it immediately and notify Security Operations.

## Account lockouts
After repeated failed sign-in attempts, an account may be temporarily locked. Support should verify the user's identity before initiating an unlock. Escalate suspected account compromise to Security Operations rather than repeatedly resetting credentials.
