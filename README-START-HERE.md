# Start here

TraceLens is documented in the root README. Follow its Windows PowerShell quick start to start MongoDB, run the FastAPI service, open the dashboard, and optionally configure grounded LLM diagnosis.

Existing experiments remain in rag-project-1 (TF-IDF) and rag-project-2 (ChromaDB + SentenceTransformers). See each experiment README for its environment and model-download requirements.
