# TraceLens frontend

React + TypeScript + Vite observability dashboard for TraceLens. It includes Overview, Projects, Runs, Compare, Findings, Events, and API settings views. The interface is designed around inspecting execution history and evidence-backed diagnostics, not building or debugging RAG applications.

## Run locally

```powershell
npm install
npm run dev
```

The default backend URL is `http://127.0.0.1:8000`; change it using the dashboard settings if required. Build for production with `npm run build`.
